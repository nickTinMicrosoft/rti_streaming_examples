Quick Start

Get up and running in minutes.

  1. Set Up Azure Resources

    Create an Event Hubs namespace and individual hubs. See the Azure Setup section below.

  2. Clone & Configure

    git clone https://github.com/nickTinMicrosoft/rti_streaming_examples.git
cd rti_streaming_examples
cp .env.example .env
# Edit .env with your connection strings

  3. Install Dependencies

    cd hospital          # or trains/ or flight-tracker/
pip install -r requirements.txt

  4. Run a Simulator

    python hospital_vitals.py

    Press Ctrl+C to stop. Data streams to Event Hub in real time.

🏥 Hospital Simulator

Two scripts that simulate a busy hospital floor with 15 patients.

hospital_vitals.py

Streams vital signs — heart rate, blood pressure, SpO2, temperature, and respiratory rate. Patient conditions shift between stable, elevated, and critical.

hospital_movement.py

Streams movement events — admissions, room transfers, X-Ray visits, and discharges. Uses the same patient IDs for joins in Fabric.

Vitals Data Schema

FieldTypeDescription

conditionstringstable, elevated, or critical
heart_rateintBeats per minute

temperature_ffloatBody temperature (°F)
spo2intOxygen saturation (%)
respiratory_rateintBreaths per minute
timestampstringUTC ISO 8601

🚇 Train Telemetry Simulator

NYC metro train data — choose between Event Hub and IoT Hub versions.

trains_eventhub.py

Sends train telemetry using a shared Event Hub producer. Simplest setup — just needs one connection string.

Event Hub

trains_iothub.py

Sends telemetry using per-device IoT Hub connections. Great for demonstrating device identity and IoT Hub routing.

IoT Hub

✈️ PiAware Flight Tracker

Live ADS-B data from a real receiver — the only simulator that uses real-world data.

What You Need

ComponentDescription
Raspberry Pi3B+ or newer
FlightAware Pro Stick PlusUSB SDR receiver (1090 MHz)
1090 MHz ADS-B AntennaOutdoor mounting recommended
MicroSD Card16 GB+ with PiAware OS

Flight Data Schema

FieldTypeDescription
hexstringICAO 24-bit aircraft address
flightstringCallsign / flight number
lat / lonfloatPosition coordinates
alt_barointBarometric altitude (ft)
gsfloatGround speed (knots)
trackfloatHeading (degrees)
squawkstringTransponder code
timestampstringUTC ISO 8601

Running

# Default (localhost:8080, 5s interval)
python flight_tracker.py

# Custom host and polling interval
python flight_tracker.py --host 192.168.1.50 --port 8080 --interval 2

💧 Water Quality Simulator

Monitors water quality across 18 sensor sites with automated anomaly detection.

water_quality.py

Streams water quality readings — pH, turbidity, chlorine residual, dissolved oxygen, temperature, and conductivity — from 18 simulated sensor sites across a water utility network. Includes automated anomaly detection that fires alerts when readings exceed safe thresholds.

Event Hub Anomaly Detection

Running

cd water-quality
pip install -r requirements.txt
python water_quality.py
